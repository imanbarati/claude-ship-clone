A functional, dependency-free clone of the Claude Ship workflow: Code Review, PR Steward and policy-based Claude Approvals, running as GitHub Actions.

View repositoryInstall in 4 steps

Code Review

Multi-lens review with Quick, Standard and Deep levels. Findings are verified against added lines and posted inline on the PR.

PR Steward

Responds to failing CI, merge conflicts and feedback. Pushes fixes, explains every change and shows how to undo it.

Claude Approvals

A policy file decides approve, request-changes or comment-only. Starts in observe mode; enforce mode submits a GitHub review.

/ship

One local command commits, pushes, opens the PR and lets the agents take it from there.

Setup

  1. Use this template or fork the repository.
  2. Add ANTHROPIC_API_KEY as a repository secret (optional; a deterministic baseline reviewer runs without it).
  3. Edit .claude-ship/config.yml and .claude-ship/policy.yml.
  4. Open a pull request — the workflows run automatically.
